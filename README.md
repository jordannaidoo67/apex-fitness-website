## Project Overview
Apex Fitness & Performance Hub is a Durban-based fitness facility offering strength training, group classes, and personal coaching. This project establishes a multi-page, semantic HTML5 website designed to present club information, showcase services, and capture new membership inquiries online.

## Project Goals & Objectives
* **Goal:** Expand digital reach, streamline customer onboarding, and reduce repetitive telephone queries.
* **Objectives:**
  * Construct a 5-page fully linked semantic HTML5 web structure.
  * Implement clear user navigation across all site pages.
  * Provide functional HTML forms for user inquiries and contact requests.

## Key Features
* Semantic HTML5 layout structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* Multi-page global navigation bar.
* Interactive membership enquiry and contact forms with input validation attributes.
* Content organized using structured headings, lists, tables, and media elements.
